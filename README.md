# TrueVote 🗳️
A decentralized blockchain voting platform built on Base Sepolia.

## Features
- Tamper-proof voting on blockchain
- Voter whitelist authentication  
- Gas-free voting via UGF
- Real-time results

## Tech Stack
React.js • Solidity • ethers.js • Base Sepolia • UGF

## Setup
1. Clone the repo
2. cp .env.example .env
3. Add your contract address to .env
4. npm install
5. npm start
